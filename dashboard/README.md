# Power BI Dashboard Specification

Create these pages after running the pipeline:

### 1. Executive Overview
- Total customers
- Revenue
- Churn rate
- At-risk customers
- Average order value

### 2. Customer Behavior
- Orders vs revenue
- Recency distribution
- Engagement by channel
- Customer value distribution

### 3. Churn Analytics
- Churn rate by segment/channel/category
- Risk-score distribution
- Model performance cards from `reports/model_results.csv`

### 4. Voice of Customer
- Positive/Neutral/Negative sentiment
- Feedback theme counts
- Top TF-IDF terms / clusters

### 5. Next-Best-Action
- Customers selected for campaign
- Recommended action
- Revenue represented by prioritized customers
